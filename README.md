# Rose-Formula
Project showing the basic code required to establish a rose shape from the formula.

## 🧵 From Blog to Code: Crochet the Rose Curve

This repo brings to life the ideas from my blog post:  
[“A Developer’s Guide to Crocheting the Rose Curve with Code”](https://dev.to/fiberartsdecoded/a-developers-guide-to-crocheting-the-rose-curve-with-code-ed5)

In the article, I explore the math behind rose curves and show how to convert that into a crochet-ready pattern using Python. This repo contains the code, pattern output, and instructions to try it yourself.
